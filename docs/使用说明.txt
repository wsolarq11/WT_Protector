WT Launcher 使用说明
====================

WT Launcher 是一个 Windows Terminal 工作区启动器：把常用项目文件夹做成卡片，
点一下就在终端里打开，自动进入对应目录并运行指定命令。

--------------------------------------
上手三步
--------------------------------------

1. 把整个文件夹解压到你喜欢的位置，双击 WTLauncher.App.exe。
   若 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

2. 点「添加第一个工作区」，填名称、选目录（点「浏览...」）、命令保持默认 pwsh，保存。

3. 点卡片即在 Windows Terminal 打开。搜索框按名称或路径过滤；勾选多张卡片后
   点「一键启动已勾选」可批量打开。

--------------------------------------
常见问题
--------------------------------------

Q: 点卡片没反应，提示找不到 wt.exe？
A: 先安装 Windows Terminal。在 PowerShell 运行：
   winget install --id Microsoft.WindowsTerminal
   装完重新打开本软件。

Q: 提示「目录不存在」？
A: 项目文件夹被移动或改名。右键卡片 →「编辑」→ 重新选择目录。

Q: 数据存在哪里？怎么备份？
A: 全部数据在软件文件夹里的 config\launcher.json 这一个文件。
   备份就是复制这个文件；想重置就删掉它。

Q: 会改电脑上的其他东西吗？
A: 不会。不写注册表、不用 AppData，所有状态都在自己的 config 文件夹里；
   删掉整个文件夹就是完全卸载。
