WT Launcher 使用说明
====================

WT Launcher 是一个 Windows Terminal 工作区启动器:把你常用的项目文件夹
做成一个个大卡片,点一下就在终端里打开——自动进入那个目录、运行你
指定的命令。适合同时维护多个项目的人。

──────────────────────────────────────
一、第一次使用
──────────────────────────────────────

1. 把整个文件夹解压到你喜欢的位置(比如 D:\Tools\WTLauncher)。
2. 双击 WTLauncher.App.exe。
   - 如果 Windows 提示"Windows 已保护你的电脑",点「更多信息」
     →「仍要运行」即可。这是未签名程序的正常提示,不是病毒。
3. 第一次打开是空白界面,点「添加第一个工作区」:
   - 名称:随便起,比如「我的项目」
   - 目录:点「浏览...」选择你的项目文件夹
   - 命令:保持默认的 pwsh(打开 PowerShell)即可
   保存后卡片就出现了,点卡片即可在 Windows Terminal 中打开。

──────────────────────────────────────
二、日常使用
──────────────────────────────────────

- 点卡片 = 打开一个终端(自动进入该项目目录)
- 搜索框 = 按名称/路径快速过滤
- 勾选多个卡片 → 点「一键启动已勾选」= 批量打开
- 「发现」按钮 = 自动扫描电脑上已安装的 AI 命令行工具
  (codex、claude 等)并一键添加为启动项。没装这些工具就忽略它。
- 右键卡片 = 编辑、删除、复制、调整顺序

──────────────────────────────────────
三、常见问题
──────────────────────────────────────

Q: 点卡片没反应,提示找不到 wt.exe?
A: 需要先安装 Windows Terminal。打开 PowerShell,运行:
   winget install --id Microsoft.WindowsTerminal
   安装完成后重新打开本软件。

Q: 提示「目录不存在」?
A: 项目文件夹被移动或改名了。右键卡片 →「编辑」→ 重新选择目录。

Q: 我的数据存在哪里?怎么备份?
A: 所有数据都在本文件夹的 config\launcher.json 这一个文件里。
   备份 = 复制这一个文件;想重置 = 删掉它,软件会从空白重新开始。

Q: 会不会改我电脑上的其他东西?
A: 不会。它不写注册表、不用 AppData,所有状态都在自己的 config
   文件夹里;删掉整个文件夹就是完全卸载。
